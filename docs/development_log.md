# Development log

Major changes in chronological order. Each entry corresponds to one commit.

## 2026 08 07, project start and dataset generator

Toolchain decision: pure Python with numpy, scipy, Pillow, OpenCV and matplotlib inside a project virtual environment. Simulation suites (process emulators, finite element tools) were considered and rejected: the deliverable must run from a plain clone with pip installed requirements, and the scored part of the generator is the SEM image formation model, which is fully expressible with array code.

Built the generator as specimen first, capture second (see architecture.md). Two layout styles implemented, DRAM and FinFET, both with per pair structural randomisation and deliberate aperiodic anchors (mat stripes for DRAM, logic cell randomness for FinFET) plus deliberately hard periodic regions (mat interiors, an SRAM block). First visual review led to one geometry correction: diffusion breaks initially erased about 43 percent of the fin field because every cell boundary carried a 1.5 gate pitch wide break; reduced to a 0.8 gate pitch break with wider cells, matching single diffusion break practice, after which the fin fabric reads like real top down CD SEM frames.

## 2026 08 07, localizer

Implemented the matched formation approach: instead of generic multi scale template matching, the reference is pushed through the same optical chain the search image went through (blur to search resolution, affine resample onto the search grid with point sampling so aliasing is reproduced), then normalized cross correlation with a coarse to fine rotation and scale search. Tie break per the problem statement: among near equal peaks, closest to the search image center. Smoke test on three pairs landed under 0.2 px error.

## 2026 08 07, evaluation harness

Added the evaluation module: per pair localization against ground truth, metrics overall and split by style and placement, tolerance curve, plots and success and failure montages with the correlation response, written to a timestamped folder under experiments per run.

## 2026 08 07, baseline results and two corrections

Baseline run on 40 mixed pairs: median error 0.153 px, every one of the 30 pairs whose window contains aperiodic content localized sub pixel with a single correlation candidate, and all 10 failures were lattice mislocks confined to deep periodic placements with 5 to 18 near equal candidates, the degeneracy the problem statement predicts. Two changes followed. First, a literature verification pass (all 23 references checked against publishers) surfaced that real DRAM local lines run 256 to 512 cells, so mats were enlarged from about 2 um to 4.5 to 9 um to match published organisation. Second, a residual disambiguation stage was added to the localizer: among near equal candidates, cell to cell reference subtraction recovers each window's deviation field and matches it against the template's, which identifies the true site whenever the window carries any defect signature, and otherwise falls back to the mandated center tie break. On the worst baseline failure (711 px mislock in a DRAM mat) the stage recovered the site to 0.07 px; on a defect free SRAM interior it correctly reported indecision, which is the physically honest outcome.

## 2026 08 07, stage two hardening and final ablation

The regenerated dataset with realistic mats exposed two stage two weaknesses. First, candidates a few pixels apart have almost fully overlapping windows, which violates the independence the median reference needs and once produced a confidently wrong answer; candidates are now clustered at half template radius and only cluster representatives are compared. Second, a leave one out reference was tried and rejected with the analysis on record: a pixelwise median over an odd number of windows is already robust to the single outlier carrying the defect signature, while leave one out over two windows degenerates to a mean polluted by the other window's content, so the full odd sized median stack is correct. The decision margin threshold was set to 0.035 from the observed separation between genuine rescues (0.045 and above) and honest indecision (0.028 and below). Final ablation on 40 pairs: without stage two 82.5 percent within 1 px, with stage two 85 percent, median error 0.107 px, mean runtime 2.2 s per pair, and the five remaining failures are all defect free periodic interiors where the localization problem is physically unidentifiable, with the algorithm reporting exactly that through its diagnostics instead of failing silently.

## 2026 08 07, domain shift hardening campaign

Three exposures to the hidden test set were closed. Rotation and scale coverage widened to plus minus 6 deg and plus minus 4 percent behind a half resolution prescreen of all 180 hypotheses, so the wider grid costs about 0.4 s. A blur bank (4, 9, 16, 25 nm) replaced the single 6 nm template blur after an independent stress generator showed correlation quality collapsing when template and search blur mismatch; the bank also improved the main dataset, where 9 nm frequently wins over the old fixed 6 nm. Contrast polarity detection from signed correlation extrema handles inverted tone conventions at no extra cost.

The stress generator (scripts/generate_stress_dataset.py) shares no code or conventions with the main pipeline: starter prompt style lattice, painted Sobel edges, plain Gaussian noise, area averaged downsampling, gamma jitter, rotations to 5 deg and scale errors to 3 percent. It drove a redesign of stage two through three diagnosed failures. First, rank inversion: in an ultra uniform world the true site can rank hundreds deep in correlation score because its own defects reduce its lattice correlation, so any top K candidate selection misses it; the residual scoring is now computed densely in closed form over every position (two raw correlations plus integral image sums). Second, lattice leakage: the template minus median residual retains systematic periodic mismatch that correlates with every aligned window; the median and its two gradient images (first order sub pixel shift terms) are now projected out by least squares before scoring. Third, decision calibration: a fixed margin is meaningless when the pool has thousands of members, so the decision is a robust z score against the candidate population. A two tier tolerance keeps the tie break semantics intact: the strict set (matches equally well) is what the center tie break applies to, while the wider noise scaled pool only feeds rescue attempts.

Outcomes on 30 independent stress pairs: 13 sub pixel including rotations to 4.5 deg and scale errors to 3 percent, 6 correct stage two rescues, and the 15 failures concentrated in anchor free wallpaper windows that are unidentifiable in principle. On the main dataset the redesign also rescued one more deep array case: 87.5 percent within 1 px, median 0.099 px, 3.2 s per pair.

## 2026 08 07, RGB optical modality

Added a brightfield optical image formation model over the same specimen canvases for the bonus: per material RGB reflectance, thin film interference color over oxide parameterized by film thickness, diffraction limited chromatic point spread (sigma 0.21 lambda over NA per channel), vignetting, illumination tilt, photon shot noise with the wide capture far below the reference exposure, white balance jitter, and no scan artifacts since optical tools are full field cameras. The localizer accepts RGB input through luminance conversion. The physics is honest about what optics can do at these fields of view: arrays are unresolved color fields, so localization succeeds only through mesoscale structure, pinning position across visible boundaries while sliding along featureless directions. This mirrors production practice, where optical tools provide coarse alignment and electron beam tools do fine addressing.

The localizer selects an optical preset automatically when the input is RGB, because the SEM band pass (25 px) removes exactly the mesoscale content that carries all optical information; the preset widens the band pass to 120 px, strengthens denoising and drops the extra template blur since the shared optics already match the two captures. On 30 optical pairs the preset recovers both coordinates within 15 px (150 nm) for 2 pairs where a stripe crossing sits in the reference field, exactly one coordinate for 13 pairs where a single boundary crosses the field (the position along the boundary is genuinely unconstrained), and nothing for the 15 pairs whose reference field is a featureless color patch. Half of optical references therefore yield a usable coarse constraint, which is the physically correct expectation for this modality and field of view.

## 2026 08 07, learned re-ranker built, measured and kept optional

Implemented the optional CNN re-ranker for the stage two decision. The classical pipeline is unchanged and still produces the candidate pool; the network only replaces the final accept or abstain rule. Each candidate is scored from a four channel stack (search window, template, window deviation field, template deviation field after periodic content removal) plus the two scalar scores, through a 17 thousand parameter CNN with a learnable null class in the softmax, trained with a within pair softmax and dihedral augmentation on 88 degenerate pairs harvested from 540 generated pairs, with labels free from ground truth. Inference is pure numpy from an exported npz verified against torch to 4e-6, so the default installation needs no learning framework; training is reproduced by the notebook and scripts with dependencies split into requirements_train.txt.

The measured verdict decided the default. Validation pair accuracy 0.692 with the abstention threshold calibrated to 1.0 precision on the validation split. On the main dataset the re-ranker ties the hand calibrated z rule at 87.5 percent within 1 px while losing one rescue to a knife edge abstention. On the held out stress generator, the transfer test the design demanded, it degrades to 30 percent within 1 px against 43.3 classical with 18 against 14 catastrophic misses: a network trained on one generator's physics does not transfer to an independent generator, and the hidden test set is by definition an independent generator. The re-ranker therefore ships as an off by default flag with its complete training and evaluation record, and the physics grounded classical decision remains the default. Two latent evaluation bugs were found and fixed along the way: the per style scatter plot crashed on the stress style name and the montage assumed ground truth corners exist, both of which had silently truncated the plots of earlier stress run folders; the affected stress evaluation was rerun complete.
